# Java & Backend — The 0-to-Hero Master Book

One coherent resource that takes you from *"I've never written code"* to
**senior / tech-lead Java backend engineering** — plus the interview prep to
land the roles along the way. Java-first and backend-focused: the language, the
JVM, Spring & Spring Boot, databases, APIs, security, system design, distributed
systems, AI/LLM integration, and the leadership craft — across **seven modules
(L0 → L6)**, every topic complete and depth-checked.

## What's inside

- **`content/`** — the book itself: hand-written Markdown, one file per topic. **This is the source of truth.**
- **`examples/`** — 21 runnable companion projects (Maven + k8s manifests), each linked to the topic it backs.
- **`docs/`** — the master index ([CONTENTS.md](docs/CONTENTS.md)), [GLOSSARY](docs/GLOSSARY.md), [ACRONYMS](docs/ACRONYMS.md), [LEARNING-PATHS](docs/LEARNING-PATHS.md).
- **`templates/`** — the authoring guidelines ([CONVENTIONS](templates/CONVENTIONS.md), [DEPTH-CHECKLIST](templates/DEPTH-CHECKLIST.md)) + copy-paste templates.
- **`scripts/`** — generators: `scripts/web/` builds the **dochub** web reader; `scripts/audio/` builds the **audio** narration.
- **`audio/`** and **`dochub/`** — *auto-generated and git-ignored* (regenerate anytime — see [GUIDE.md](GUIDE.md)).

## The seven modules

| Module | Tier | Focus |
|---|---|---|
| **L0 — Foundations** | Absolute beginner | How programs run, syntax, control flow, methods, arrays |
| **L1 — Core Java & OOP** | Beginner → Junior | OOP, collections, exceptions, generics, JUnit |
| **L2 — Intermediate & Backend Foundations** | Junior → Mid | Streams/functional, I/O, HTTP, DNS, SQL/JDBC |
| **L3 — Advanced Java & the JVM** | Mid → Senior | Concurrency, memory model, GC, performance, patterns |
| **L4 — Backend Engineering** | Senior | Spring/Boot, REST/GraphQL, JPA, testing, security, observability, Docker, AI/LLM |
| **L5 — Architecture & Leadership** | Lead / Staff | System design, distributed systems, case studies, ADRs, leadership |
| **L6 — Interview Mastery** | All levels | DSA, LLD/HLD, behavioral, company tracks, mock interviews |

See **[GUIDE.md](GUIDE.md)** for everything else — reading the book, generating the web/audio versions, and the editing workflow.
