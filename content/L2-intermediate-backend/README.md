# L2 — Intermediate Java & Backend Foundations

Modern idiomatic Java plus the backend vocabulary every server-side developer needs before touching a framework.

> [!NOTE]
> **Tier:** Junior to Mid  
> **Prerequisites:** [L1 module](../L1-core-java/)

## What you'll learn

- Functional Java: lambdas, streams, Optional.
- Build tools and the everyday developer workflow.
- How the web works: networking, HTTP, and REST basics.
- Relational databases, SQL, and JDBC.
