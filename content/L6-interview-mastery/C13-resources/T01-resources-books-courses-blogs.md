# Resources — Books, Courses, Blogs, Communities

A curated list of **the highest-leverage external resources** for FAANGM and MNC Java interview prep. Organised by category. **You don't need all of these** — pick 1-2 per category that suit your learning style.

## Books — The Canonical SWE Library

### Java + JVM

- **[Effective Java (3rd ed) — Joshua Bloch](https://www.oreilly.com/library/view/effective-java-3rd/9780134686097/)** — Required for senior Java interviews. Knowing the items by number is bonus.
- **[Java Concurrency in Practice — Brian Goetz](https://jcip.net/)** — The canonical reference for JMM, threading, locks. Essential for senior + banking interviews.
- **[Modern Java in Action — Raoul-Gabriel Urma](https://www.manning.com/books/modern-java-in-action)** — Streams, Optional, async — modern idioms.
- **[The Well-Grounded Java Developer (2nd ed) — Benjamin Evans](https://www.manning.com/books/the-well-grounded-java-developer-second-edition)** — JVM internals, modules, modern Java.
- **[Optimizing Java — Benjamin Evans, James Gough, Chris Newland](https://www.oreilly.com/library/view/optimizing-java/9781492025788/)** — JVM performance + profiling.

### Algorithms + DSA

- **[Cracking the Coding Interview — Gayle Laakmann McDowell](http://www.crackingthecodinginterview.com/)** — The classic; still relevant for warm-up.
- **[Elements of Programming Interviews (Java) — Aziz / Lee / Prakash](https://elementsofprogramminginterviews.com/)** — Denser than CTCI; better for senior.
- **[Algorithm Design Manual — Steven Skiena](https://www.algorist.com/)** — More theoretical; pattern catalogue.
- **[CLRS — Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/)** — The canonical academic ref. Reference, not cover-to-cover.

### System Design

- **[Designing Data-Intensive Applications — Martin Kleppmann](https://dataintensive.net/)** — **THE** book for senior+ system design. Required reading.
- **[System Design Interview Vol 1 + 2 — Alex Xu](https://bytebytego.com/)** — Concise case-study format.
- **[Database Internals — Alex Petrov](https://www.databass.dev/)** — DB engine deep-dive.
- **[Streaming Systems — Tyler Akidau et al.](https://www.oreilly.com/library/view/streaming-systems/9781491983867/)** — For Kafka / streaming roles.

### Software Engineering Craft

- **[A Philosophy of Software Design — John Ousterhout](https://web.stanford.edu/~ouster/cgi-bin/aposd.php)** — Best modern book on design.
- **[The Pragmatic Programmer (20th anniv ed) — Hunt + Thomas](https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/)** — Timeless principles.
- **[Working Effectively with Legacy Code — Michael Feathers](https://www.oreilly.com/library/view/working-effectively-with/0131177052/)** — For senior+ refactoring.

### Career + Interview Strategy

- **[The Tech Resume Inside Out — Gergely Orosz](https://thetechresume.com/)** — Highest-signal resume guide.
- **[Cracking the PM Interview — McDowell + Bavaro](https://www.crackingthepminterview.com/)** — (PM-flavoured, useful for cross-functional roles).
- **[The Software Engineer's Guidebook — Gergely Orosz](https://www.engguidebook.com/)** — Career navigation.
- **[Staff Engineer — Will Larson](https://staffeng.com/book)** — The Staff+ track guide.

### Leadership + Soft Skills

- **[The Manager's Path — Camille Fournier](https://www.oreilly.com/library/view/the-managers-path/9781491973882/)** — IC + management transition.
- **[An Elegant Puzzle — Will Larson](https://lethain.com/elegant-puzzle/)** — Engineering management essays.
- **[Work Rules! — Laszlo Bock](https://www.workrules.net/)** — Google's HR philosophy; XYZ resume formula.
- **[Resilient Management — Lara Hogan](https://larahogan.me/)** — Practical management.

## Recommended "Starter Pack"

If you only have time for 5 resources for a 12-week prep:

1. **NeetCode 150** (free) — DSA pattern coverage.
2. **Designing Data-Intensive Applications** (book) — system design + distributed systems depth.
3. **Effective Java** (book) — Java idioms for interviews.
4. **The Tech Resume Inside Out** (book) — resume + LinkedIn.
5. **Pragmatic Engineer newsletter** (free subscribe) — industry trends + job market.

That's ~$80 + free; covers 80% of needs.

## Recap

This resource list is **navigation, not curriculum**. Pick 1-2 per category. The L6 chapters themselves contain the synthesised content; these external resources are for **going deeper** on specific areas where you want more depth.

The single highest-ROI external resources for FAANGM Java prep:

- **Designing Data-Intensive Applications** (system design)
- **Effective Java** + **Java Concurrency in Practice** (Java depth)
- **NeetCode 150** (DSA)
- **Hello Interview / ByteByteGo** (company-specific system design)
- **The Pragmatic Engineer** (industry awareness)
