# L0 — Foundations

The starting line. Assumes zero programming experience. By the end you can install Java, write and run a program, and understand the building blocks every later module relies on.

> [!NOTE]
> **Tier:** Absolute beginner  
> **Prerequisites:** None — start here.

## What you'll learn

- How programs run and what the JDK/JRE/JVM actually are.
- Java syntax: variables, types, operators, expressions.
- Control flow, loops, methods, arrays, and strings.
- Compiling and running Java from an IDE and the command line.
