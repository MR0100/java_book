# L3 — Advanced Java & the JVM

The jump from writing working code to understanding what the machine is doing: concurrency, the JVM, performance, patterns.

> [!NOTE]
> **Tier:** Mid to Senior  
> **Prerequisites:** [L2 module](../L2-intermediate-backend/)

## What you'll learn

- Concurrency from threads to virtual threads and the memory model.
- JVM internals: class loading, bytecode, JIT, garbage collection.
- Performance: profiling, benchmarking, finding bottlenecks.
- Design patterns with idiomatic modern Java.
