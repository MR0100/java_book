Resources — Books, Courses, Blogs, Communities

A curated list of the highest-leverage external resources for FAANGM and MNC Java interview prep. Organised by category. You don't need all of these — pick 1-2 per category that suit your learning style.

Books — The Canonical SWE Library#

Java + JVM#

  • Effective Java (3rd ed) — Joshua Bloch — Required for senior Java interviews. Knowing the items by number is bonus.
  • Java Concurrency in Practice — Brian Goetz — The canonical reference for JMM, threading, locks. Essential for senior + banking interviews.
  • Modern Java in Action — Raoul-Gabriel Urma — Streams, Optional, async — modern idioms.
  • The Well-Grounded Java Developer (2nd ed) — Benjamin Evans — JVM internals, modules, modern Java.
  • Optimizing Java — Benjamin Evans, James Gough, Chris Newland — JVM performance + profiling.

Algorithms + DSA#

  • Cracking the Coding Interview — Gayle Laakmann McDowell — The classic; still relevant for warm-up.
  • Elements of Programming Interviews (Java) — Aziz / Lee / Prakash — Denser than CTCI; better for senior.
  • Algorithm Design Manual — Steven Skiena — More theoretical; pattern catalogue.
  • CLRS — Introduction to Algorithms — The canonical academic ref. Reference, not cover-to-cover.

System Design#

  • Designing Data-Intensive Applications — Martin Kleppmann — THE book for senior+ system design. Required reading.
  • System Design Interview Vol 1 + 2 — Alex Xu — Concise case-study format.
  • Database Internals — Alex Petrov — DB engine deep-dive.
  • Streaming Systems — Tyler Akidau et al. — For Kafka / streaming roles.

Software Engineering Craft#

  • A Philosophy of Software Design — John Ousterhout — Best modern book on design.
  • The Pragmatic Programmer (20th anniv ed) — Hunt + Thomas — Timeless principles.
  • Working Effectively with Legacy Code — Michael Feathers — For senior+ refactoring.

Career + Interview Strategy#

  • The Tech Resume Inside Out — Gergely Orosz — Highest-signal resume guide.
  • Cracking the PM Interview — McDowell + Bavaro — (PM-flavoured, useful for cross-functional roles).
  • The Software Engineer's Guidebook — Gergely Orosz — Career navigation.
  • Staff Engineer — Will Larson — The Staff+ track guide.

Leadership + Soft Skills#

  • The Manager's Path — Camille Fournier — IC + management transition.
  • An Elegant Puzzle — Will Larson — Engineering management essays.
  • Work Rules! — Laszlo Bock — Google's HR philosophy; XYZ resume formula.
  • Resilient Management — Lara Hogan — Practical management.
