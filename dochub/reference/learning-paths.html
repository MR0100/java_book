🌱 Path 0: Complete Beginner → Junior#

Who it's for: You've never written production code, or you know another language but not Java's syntax and tooling. Goal: write, compile, and run real Java programs and land a junior role.

Time: 3–4 months at ~10 hrs/week. Cadence: read one topic, then immediately code it.

Month Focus Sequence
1 CS + Java syntax L0/C01 CS Foundations → L0/C02 Java Core (T01–T19: structure, types, operators, control flow, methods, arrays)
2 Tooling + first programs L0/C03 Tools & Environment → L0/C04 Hands-On labs → L0/C05 Best Practices
3 OOP L1/C01 OOP (classes, encapsulation, inheritance, polymorphism, interfaces)
4 Collections + consolidate L1/C02 Collections & Core APIs → L0/C08 Cheatsheets → review with L0/C06 Interview Prep

Done when: you can build a small CLI app from scratch with classes, collections, and clean structure. Next: Path 1.

🟢 Path 1: Junior → Mid-Level Backend Engineer#

Who it's for: 0–2 years' experience, Java basics OK, want to ship production code with confidence. Time: 3–4 months at ~10 hrs/week. Goal: comfortably ship CRUD microservices with proper error handling, testing, and observability.

Month 1 — Solidify Java Core#

Week Topics
1 — Modern Java foundation L0/C02 T01–T05 (variables/types/operators, if rusty) · L1/C01 Classes & encapsulation · Interfaces: default/static/private (diamond problem) · equals/hashCode/toString (most-asked Java topic)
2 — Modern Java features Records · Sealed classes · Optional · L2/C01 Streams + lambdas
3 — Collections deep L1/C02 List/Set/Map basics · HashMap internals (critical) · Iterators / fail-fast / CME
4 — Pitfalls + idioms L1 Idioms (37 patterns) · L1 Pitfalls (45 traps: Integer cache, String pool) · L1/C09 Cheatsheets

Month 2 — Backend Foundations#

Week Topics
5 — HTTP, REST, networking L2/C03 Networking (TCP/TLS/HTTP) · L2/C04 Web & REST
6 — Spring Boot intro L4/C01 Spring framework basics (IoC, DI, starters) · Auto-config & starters (Boot 2→3 migration)
7 — Spring MVC + REST Spring MVC REST controllers · Exception handling @ControllerAdvice · Bean validation
8 — SQL + JDBC L2/C05 SQL deep + JDBC · Spring Data

Month 3 — Testing, Concurrency Basics, Deployment#

Week Topics
9 — Testing L1/C03 Testing fundamentals (JUnit 5, Mockito) · L4/C09 Testing advanced (Spring test slices, Testcontainers)
10 — Concurrency basics Threads & Runnable · Thread lifecycle · synchronized & monitors · Executors & thread pools
11 — Observability + ops L4/C10 Observability basics · OpenTelemetry tracing · Twelve-Factor App
12 — Deployment L4/C10 Docker + Kubernetes basics · L4 best practices (15 operational anti-patterns)

Month 4 — Capstone#

  • Build a complete REST service with Spring Boot 3 + Java 21.
  • Include validation, error handling, testing, metrics, logs, and structured config.
  • Deploy to local Kubernetes or AWS Free Tier.

Done when: you've shipped the capstone end-to-end. You're now Mid-Level → Path 2.

🟡 Path 2: Mid-Level → Senior Backend Engineer#

Who it's for: 2–5 years' experience, comfortable with Spring Boot CRUD, want depth. Time: 4–6 months at ~10 hrs/week. Goal: deep JVM understanding; design microservices, optimize performance, debug production.

Month 1 — JVM Internals#

Week Topics
1 — Memory model + JMM Java Memory Model: happens-before/volatile · Heap/stack/metaspace
2 — Garbage collection GC algorithms (Serial→ZGC/Shenandoah) · GC tuning & monitoring (5 workload recipes) · JVM flags & ergonomics
3 — JIT + AOT JIT C1/C2/Tiered · AOT / GraalVM native image
4 — Memory leaks Memory leaks & heap-dump analysis

Month 2 — Advanced Concurrency#

Week Topics
5 — Locks + atomics Locks: ReentrantLock/ReadWrite/Stamped · Atomic variables (LongAdder, ABA)
6 — Concurrent collections + synchronizers Synchronizers: Semaphore/Latch/Barrier/Phaser · Concurrent collections (ConcurrentHashMap evolution)
7 — Async + composition CompletableFuture & async composition · Fork/Join framework
8 — Virtual threads (Java 21+) Virtual threads (Project Loom)

Month 3 — Spring Deep + Persistence#

Week Topics
9 — Spring AOP + transactions Spring AOP (@Transactional self-invocation) · Transactions with JPA
10 — JPA advanced L4/C02 JPA & Hibernate (N+1, EntityGraph, optimistic locking)
11 — NoSQL + caching L4/C04 NoSQL & caching (Redis production-grade) · Caching at scale
12 — Security + OAuth2 Spring Security · OAuth2/OIDC/JWT

Month 4 — Messaging + Distributed Basics#

Week Topics
13–14 — Kafka deep L4/C07 Kafka fundamentals · Kafka deep: partitions/consumer groups/offsets
15 — Resilience Resilience patterns · Idempotency & dedup
16 — SLI/SLO + ops Reliability: SLI/SLO/SLA, redundancy, failover

Months 5–6 — Production Experience#

  • Take full ownership of a service in production.
  • Run an incident retrospective (see the reliability topic for postmortem structure).
  • Drive 1–2 architectural decisions; document them as ADRs.

You're now Senior → Path 3.

🟠 Path 3: Senior → Staff Engineer#

Who it's for: 5–10 years' experience, can ship services, want architecture authority. Time: 6–9 months at ~10 hrs/week. Goal: lead architecture, drive cross-team decisions, design distributed systems.

Phase A — Architecture Foundations (Months 1–2)#

Layered → Hexagonal/Clean/Onion → DDD → Monolith vs Microservices vs Modular → Microservices decomposition → Twelve-Factor App → Anti-Corruption Layer → Trade-off analysis

Phase B — Distributed Systems Theory (Months 3–4)#

CAP/PACELC → Consistency models → Consensus: Raft/Paxos → Replication → Partitioning & consistent hashing → Distributed locking → Logical/vector clocks → Load balancing L4/L7 → Scaling & statelessness → Rate limiting

Phase C — Distributed Patterns (Month 5)#

Sync vs async comms → API Gateway & Service Mesh → Event Sourcing → CQRS → Saga → Distributed transactions 2PC/Saga → Strangler Fig & migration

Phase D — Worked Designs (Months 6–7)#

Study and re-implement each end-to-end: Methodology framework → URL Shortener → Rate Limiter → News Feed → Chat → Payments → Notifications → Ride-Hailing

Phase E — Leadership (Months 8–9)#

L5/C03 Engineering Leadership — career, mentoring, communication, influence.

You're now Staff → Path 4 for promotion prep.

🔴 Path 4: Staff → Principal / Senior Staff (Interview Prep)#

Who it's for: 8+ years' experience, Staff at your current company, targeting Staff/Principal/Sr. Staff at FAANGM or Indian unicorns/banking. Time: 3 months focused. Goal: land an offer at your target level.

Month 1 — Interview Foundations#

Week Topics
1 — The interview system Leveling MNC vs FAANGM · Funnel · Rubric & signals · Communication mechanics · Prep system & cadence
2 — DSA refresh L6/C02 — 15 pattern sets of worked DSA solutions (2–3 hrs per pattern; target comfort with all)
3 — System design HLD framework · L6/C03 worked HLD case studies
4 — Behavioral STAR/CAR/SBI

Month 2 — Company-Specific Tracks#

Pick 3–5 target companies and study their tracks: Amazon Leadership Principles · Google/Meta/Apple/Netflix/Microsoft/Flipkart/unicorns/banking tracks

Month 3 — Q&A Banks + Resume + Negotiation#

Track Topics
Q&A banks (one bank/day) L6/C06 — staff-level Q&A banks
Resume + job search L6/C05 Resume, LinkedIn, GitHub, referrals · Pipeline tracking · Offer evaluation & negotiation
Final week L6/C11 — all cheatsheets

🟣 Path 5: Career Switcher → Java Backend#

Who it's for: coming from Python/Node/PHP/etc., want to land a Java backend role. Time: 6 months. Cadence: ~12 hrs/week (you're moving fast but on familiar engineering ground).

Phase Months What to do
1 — Java fundamentals 1–2 Path 1 weeks 1–8 (Java core + backend foundations)
2 — Backend / Spring Boot 3–4 Path 2 months 3–4 (Spring deep + persistence + messaging)
3 — Interview prep 5–6 STAR — frame your switch story · L6/C02 DSA (especially for FAANG-style loops) · L6/C06 Java/Concurrency/Collections/Spring Q&A banks

🟤 Path 6: Production Ops / SRE Track#

Who it's for: a Java engineer moving into SRE / Platform Engineering. Time: 4–5 months at ~10 hrs/week.

Phase Months What to do
1 — JVM operations 1–2 L3/C02 JVM internals · L3/C04 Tools & Environment (jcmd, JFR, async-profiler)
2 — Observability 2–3 L4/C10 DevOps & Observability (all topics) · SLI/SLO/SLA
3 — Distributed systems 3–4 L5/C02 — all distributed-systems topics
4 — Incidents + on-call 4–5 Practice writing postmortems · drive chaos-engineering exercises · build operational dashboards
